# 유지보수 계획

## 정기 작업

- 매주 Dependabot/CodeQL/CI 결과 검토
- Spring Boot, PostgreSQL, Gradle, Bouncy Castle, ImageIO 보안 릴리스 검토
- 월 1회 깨끗한 PostgreSQL에서 Flyway와 전체 Testcontainers 테스트
- 관리자 조치/대화 조사/원장 대조 감사
- 업로드 저장소 용량, 고아 파일, DB 백업 복구 훈련

1. 요구사항과 위협 모델 갱신
2. 새 Flyway 파일 추가(기존 마이그레이션 수정 금지)
3. 정상·실패·권한·경계 테스트 동시 작성
4. 전체 PostgreSQL 테스트와 `bootJar`
5. 비밀값/개인정보/대형 파일 점검
6. PR 보안 영향 기록과 리뷰

## 사고 대응
